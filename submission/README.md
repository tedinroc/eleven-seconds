# Submission

`project.json` holds the project entry for the Monad Blitz Shanghai submission (fields `name`,
`description`, `url`, `github`). The description is in Simplified Chinese (about 600 characters) and
only uses numbers measured on Monad testnet on 2026-10-17 (see the main [README](../README.md)).

- `url`: the read-only on-chain war room (https://eleven-seconds.pages.dev).
- `github`: the public repository URL.

Checklist before submitting:

1. The GitHub repository is public at the `github` URL.
2. The numbers in `description` match the latest testnet run.
3. Screenshots contain no private keys or file paths.
